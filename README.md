# Pulse | Live Dashboard

A live analytics dashboard with a streaming feed, animated numbers and charts built from scratch in SVG.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Put it on GitHub
1. github.com par naya **empty** repository banao, naam: `realtime-dashboard`
2. Is folder ke andar:
```bash
git init
git add .
git commit -m "First version"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/realtime-dashboard.git
git push -u origin main
```

## Live on Vercel (free)
1. vercel.com par login karo (GitHub se).
2. **Add New > Project** aur `realtime-dashboard` repo chuno.
3. Framework **Vite** khud detect hoga. Settings ko waise hi rehne do.
4. **Deploy** dabao. Link milega: `https://realtime-dashboard.vercel.app`
5. Us link ko `portfolio.js` ke `live:` field mein daal do.
